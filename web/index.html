01.3

Sensor, click & performance tuning

Onboard hardware filters
Click debounce

Lower reduces click latency; increase if switches double-click.

0 ms
Motion Sync

Synchronizes sensor reads with USB frames for consistent frame pacing.

Angle Snapping

Smooths nearly horizontal or vertical lines.

Ripple Control

Reduces high-CPI sensor jitter above 10,000 CPI.

Performance / Turbo mode

Enables high-speed wireless / max sensor scan mode (uses more battery).

20K Scan Mode

Locks sensor framerate to 20,000 FPS (Scyrox V8S).

Anti-mistouch

Ignores spurious optical/mechanical double triggers.

Slamclick Filter

Prevents accidental clicks when setting the mouse down hard.

Motion Jitter Filter

Additional high-frequency sensor smoothing filter.

Sensor Glass Mode

Optimizes tracking on glass mousepads (locks LOD to 1.0 / 2.0 mm).

Disable LED on Lift-Off

Turns off the stage/scroll LED while the mouse is lifted (v2).

Force Max Sensor FPS

Locks sensor framerate to maximum even when stationary (v2).

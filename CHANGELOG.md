# Changelog

Notable user-visible changes to Mouse Tool. Updated with every merge to local `dev`; dates are merge dates (2026). Ticket IDs refer to the Tephra ledger.

## Unreleased

### Added
- **Shared `devices/` registry, Razer fallback guard, and wired Viper Mini Tier 1 slice**: extracted a single versioned `devices/devices.json` + `devices/schema.json` registry (81 models, 17 profiles, 129 matches, pinned upstream provenance, separated USB/Bluetooth/Logitech WPID namespaces) shared by Python and WebHID with a deterministic `tools/generate_udev_rules.py` generator for `platform/linux/60-mousetool.rules`. Closed the broad Razer vendor fallback so unknown Razer mice stay safely `Tier 0 · Pointer only` (zero vendor frames sent), and added a `Tier 1 · Read-only` profile for the wired Razer Viper Mini (`1532:008a`, `0xff` firmware + X/Y DPI getters only, writes blocked at dispatch in Python and WebHID pending physical hardware trial) with explicit Tier 0/1/2 UI badges and provenance (MT-016, 11-22, verified 94.9/100, same-family reviewer). Run `./install.sh --udev` when ready to test the physical Viper Mini.
- **Windows Raw Accel backend, installer, and persistence**: `mousetool serve` runs on Windows without Linux-only failures, reads/applies/resets Raw Accel curves with bounded validation and logon replay under `%LOCALAPPDATA%\mousetool`, and reports Windows backend and driver state honestly in the Acceleration tab. Includes a per-user `install.ps1` (Start Menu + Startup shortcuts and `-Uninstall`), `read-rawaccel.ps1`, fake-writer unit tests, and a reversible hardware check script `test-windows.py` verified on Windows 11 (MT-013, 11-22, verified 92.0/100, cross-provider reviewer).
- **Battery on any desktop**: a background watcher reads each wireless mouse's battery once, shares it with the page and the command line, and sends a desktop notification at 20% and again at 10% (re-armed after charging). `mousetool battery --waybar` prints one line of JSON for Waybar-style bars. Notifications can be turned off from the Power settings (MT-009, 11-21, verified 85.7/100, cross-provider reviewer).
- **Raw Accel export (Windows step 1)**: an offline preview and export of your acceleration curve in Raw Accel's format, with an equivalence check that says plainly when the curve cannot be verified (MT-003, 11-21, verified 88.3/100, same-family reviewer).
- **Pointer settings on more desktops**: Plasma, Hyprland, COSMIC and GNOME backends alongside niri, with plain-language messages when a tool is missing or the desktop isn't supported (MT-005, 11-20, verified 87.9/100). Negative speeds on Plasma and niri detection when the helper starts early are fixed.
- **Live speed and swipe indicator** on the acceleration curve graph, plotting where your current mouse speed sits on the curve and showing swipes (MT-001, 11-20, verified 86.9/100). The reconnect and accelerated-sample issues found in review are fixed.

### Changed
- **UX polish, draggable DPI stage markers, Tier info modal, fixed polling meter & zero tab shift**: removed the redundant Quick DPI row from Sensitivity → Tracking (keeping CLI `mousetool dpi` and driver `setDpi`) and the redundant Buttons footer text; fixed the Acceleration Y-curve dashed swipe highlight overlap via an SVG `<clipPath>` locked to the swipe band; made the top-bar Tier badge (plus Device → Support `ⓘ`) open a Studio-styled modal explaining Tier 2, Tier 1, and Tier 0 and highlighting the active mouse; made DPI stage pips directly draggable along the log scale (with live preview, step snapping, bounds clamping, keyboard nudging, and a single write on release); locked the live polling rate meter (`#hzBox`) to fixed `440 × 58 px` dimensions; and reserved bold tab widths so navigation tabs stay locked to `0.00 px` horizontal shift across switches (MT-024, 11-23, verified 96.7/100, same-family reviewer).
- **Total UX polish, guided acceleration driver setup, and plain-English copy**: tightened verbose/jargon-heavy helper text and subtitles across every tab into calm plain English while moving optional technical details (protocol log, Raw Accel export, advanced provenance) into collapsible disclosures; added strictly read-only `setup` diagnostics to `/api/status` and a numbered in-app **Guided Setup** card in the Acceleration tab for `mouseaccel` (Linux) and Raw Accel (Windows) with status pills, one-click copyable commands, direct Raw Accel download link, and live `Check again`; added a 1–2 step Quick Start in `README.md`; raised light-mode Tier 1/2 badge contrast above WCAG AA (`6.1:1+`); and added split `X×Y DPI` readouts on fleet cards (MT-017, 11-23, verified 96.0/100, same-family reviewer).
- **UI polish & polling-rate meter fix**: fixed the live polling-rate meter over-reporting 2k mice as 4400–6600 Hz (confirmed all driver 2000 Hz packet encodings are accurate; fixed dual `pointerrawupdate` + `pointermove` interleaving and instantaneous `1/dt` EMA spikes via a single-source sliding-window estimator in `web/polling_meter.js`), eliminated horizontal layout shift when vertical scrollbars appear (`scrollbar-gutter: stable both-edges`), standardized all card header bars across tabs to a uniform 44 px height, refined the Buttons tab mouse wireframe contour with flush Forward/Back side buttons, and aligned the acceleration graph legend with exact inline SVG swatches matching plotted strokes, dashes, and paired X/Y Live & Swipe peak markers (MT-018, MT-019, MT-020, MT-022, MT-023, 11-23, verified 96.2/100, same-family reviewer).
- **Modular package & web layout**: split the single `mousetool.py` and `index.html` files into a stdlib-only `mousetool/` Python package (per-brand `drivers/`, `accel/` backends, `cli`, `server`, `hid_discovery`, `motion`, `battery`, `desktop_pointer`) behind a thin root `mousetool.py` shim, native browser ES modules under `web/` (zero build step, strict static path-traversal rejection), and tidy `tests/`, `platform/{linux,windows}/` (keeping root `install.sh` / `install.ps1` forwarding wrappers), `tools/`, and `pyproject.toml` with zero behaviour changes (MT-015, 11-22, verified 96.9/100, same-family reviewer).
- **Hosted-page helper (design and skeleton only)**: a design for a hosted web page plus a small optional local helper, and a first Rust skeleton of that helper in `agent/` (pairing code, origin-bound access, loopback only). Nothing uses it yet; the existing app is unchanged (MT-011 step 1, 11-21, verified 88.6/100, cross-provider reviewer).
- **mouseaccel support**: mousetool now uses the `mouseaccel` kernel module when it is loaded and falls back to `maccel` otherwise, with the module in use shown on the Acceleration tab. Saving a stale draft after the backend changes is refused instead of overwriting the other module, the privileged helper no longer follows symlinks, and unreadable parameters now say so (MA-002, 11-21, verified 89.9/100, cross-provider reviewer). Install the new udev rule with `./install.sh --mouseaccel-perms`; nothing is loaded or swapped for you.
- **README screenshots**: six full-size screenshots of the sensitivity, acceleration, desktop pointer and tuning views, a script that regenerates them, and corrected hardware and command-line notes (MT-004, 11-21, verified 90.2/100, cross-provider reviewer).
- **Mouse outline and device text**: a redrawn mouse wireframe shape and a cleaner device-name font that fits at narrow widths (MT-008/010, 11-21, verified 93.3/91.4, same-family reviewer).

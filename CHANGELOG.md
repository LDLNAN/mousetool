# Changelog

Notable user-visible changes to Mouse Tool.

## Unreleased

### Added
- **Custom acceleration curves**: interactive drawn curve editor directly on the Acceleration graph (click to add control points, drag to shape with automatic neighbor clamping, right-click or Delete to remove, keyboard nudging, numeric speed/multiplier inputs, and starter presets), backed by the `mouseaccel` kernel `LUT_POINTS` / `MODE=4` interface on Linux and Raw Accel `LookUpTable` (Sensitivity mode) on Windows, with an honest preview-only notice on legacy `maccel`.
- **Shared `devices/` registry, Razer fallback guard, and wired Viper Mini Tier 1 support**: extracted a single versioned `devices/devices.json` + `devices/schema.json` registry (81 models, 17 profiles, 129 matches, pinned upstream provenance, separated USB/Bluetooth/Logitech WPID namespaces) shared by Python and WebHID with a deterministic `tools/generate_udev_rules.py` generator for `platform/linux/60-mousetool.rules`. Closed the broad Razer vendor fallback so unknown Razer mice stay safely `Tier 0 · Pointer only` (zero vendor frames sent), and added a `Tier 1 · Read-only` profile for the wired Razer Viper Mini (`1532:008a`, `0xff` firmware + X/Y DPI getters only, writes blocked in Python and WebHID pending hardware verification) with explicit Tier 0/1/2 UI badges. Run `./install.sh --udev` to update udev rules.
- **Windows Raw Accel backend, installer, and persistence**: `mousetool serve` runs on Windows without Linux-only failures, reads/applies/resets Raw Accel curves with bounded validation and logon replay under `%LOCALAPPDATA%\mousetool`, and reports Windows backend and driver state in the Acceleration tab. Includes a per-user `install.ps1` (Start Menu + Startup shortcuts and `-Uninstall`), `read-rawaccel.ps1`, unit tests, and a reversible hardware check script `tools/test-windows.py` verified on Windows 11.
- **Battery on any desktop**: a background watcher reads each wireless mouse's battery once a minute, shares it with the web UI and CLI, and sends desktop notifications at 20% and 10% (re-armed after charging). `mousetool battery --waybar` prints single-line JSON for Waybar-style status bars. Notifications can be toggled from the Power tab.
- **Raw Accel export**: offline preview, export, and import of acceleration curves in Raw Accel v1.7.1 format with automated curve equivalence checks.
- **Pointer settings across Linux desktops**: Plasma (Wayland), Hyprland, COSMIC, and GNOME backends alongside niri, with clear status messages when a tool is missing or a desktop is unsupported.
- **Live speed and swipe indicator**: plots live cursor speed and swipe peak bands directly on the acceleration curve graph.

### Changed
- **Non-blocking native device I/O & honest readback status**: offloaded native HID discovery, status reads, and setting writes to a bounded background worker so tab switches, theme toggles, and scrolling never stall during mouse retries; added device/generation tagging to reject stale replies and prevent duplicate writes, clear live readback on uncertain writes while preserving edited DPI drafts, and surface explicit Ready, Busy, Disconnected, Discovery failed, and Stale states with WCAG AA contrast.
- **Draggable DPI stage markers, Tier info modal, fixed polling meter & zero tab shift**: made DPI stage markers directly draggable along the log scale (with live preview, step snapping, bounds clamping, keyboard nudging, and a single hardware write on release); made the top-bar Tier badge and Device → Support `ⓘ` open a modal explaining Tier 2, Tier 1, and Tier 0 support tiers while highlighting the active mouse; removed redundant Quick DPI controls and Buttons footer copy; clipped the Acceleration Y-curve dashed swipe highlight cleanly to the swipe band; locked the live polling rate meter (`#hzBox`) to fixed `440 × 58 px` dimensions; and reserved bold tab label widths for zero horizontal shift across tab switches.
- **Guided acceleration driver setup & plain-English copy**: simplified helper copy across every tab while moving optional technical details (protocol log, Raw Accel export, advanced provenance) into collapsible disclosures; added read-only `setup` diagnostics to `/api/status` and a numbered in-app **Guided Setup** checklist in the Acceleration tab for `mouseaccel` (Linux) and Raw Accel (Windows) with status badges, one-click copyable commands, direct Raw Accel download link, and live `Check again`; improved light-mode Tier badge contrast above WCAG AA; and added split `X×Y DPI` readouts on fleet cards.
- **UI polish & polling-rate meter accuracy**: fixed the live polling-rate meter over-reporting 2000 Hz mice via a single-source sliding-window estimator in `web/polling_meter.js`, eliminated horizontal layout shift when vertical scrollbars appear (`scrollbar-gutter: stable both-edges`), standardized card header bars to a uniform 44 px height, refined the Buttons tab mouse wireframe contour with flush side buttons, and aligned the acceleration graph legend with inline SVG swatches matching plotted strokes and markers.
- **Modular package & web layout**: split the single-file script and HTML into a stdlib-only `mousetool/` Python package (`drivers/`, `accel/`, `cli`, `server`, `hid_discovery`, `motion`, `battery`, `desktop_pointer`) behind the root `mousetool.py` entry point, native browser ES modules under `web/` (zero build step), and organized `tests/`, `platform/{linux,windows}/`, `tools/`, and `pyproject.toml`.
- **Hosted-page helper (design and skeleton)**: added design documentation (`docs/helper-design.md`) and a Rust loopback helper skeleton in `agent/` (pairing code, origin-bound bearer auth, loopback-only listener).
- **`mouseaccel` kernel module support**: prefers the `mouseaccel` kernel module when loaded and falls back to `maccel` (legacy) otherwise, showing the active module in the Acceleration tab and installing group permissions via `./install.sh --mouseaccel-perms`.
- **README screenshots & capture tool**: added six high-resolution light/dark screenshots and `tools/capture_screenshots.py`.
- **Mouse wireframe & typography**: redrawn mouse wireframe contour and cleaner device-name typography at narrow widths.
